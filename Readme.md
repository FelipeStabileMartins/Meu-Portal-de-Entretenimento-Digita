🎬 Meu Portal de Entretenimento Digital

[📌 Sobre o projeto](https://img.shields.io/badge/%F0%9F%93%8C-Sobre%20o%20projeto-red)

Este projeto foi desenvolvido como atividade do curso Técnico em Desenvolvimento de Sistemas da ETEC, com o objetivo de praticar a criação de páginas web utilizando HTML e CSS.

O portal reúne conteúdos de entretenimento organizados em três seções principais.

[🎮 Seções do portal](https://img.shields.io/badge/%F0%9F%8E%AE-Se%C3%A7%C3%B5es%20do%20portal-purple)

Filmes e Séries: apresenta filmes e séries de diferentes gêneros.

Música e Podcasts: apresenta artistas e bandas de estilos musicais variados.

Games e Tecnologia: apresenta jogos e conteúdos relacionados à tecnologia.

[🎯 Objetivo](https://img.shields.io/badge/%F0%9F%8E%AF-objetivo-green)

Praticar os conhecimentos de HTML e CSS, utilizando imagens, links, classes, identificadores (id), comentários e Flexbox para organizar os conteúdos em três colunas.
